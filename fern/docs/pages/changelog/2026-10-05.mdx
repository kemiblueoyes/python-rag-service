Saved evaluation reports are now available for The Doc Landscape corpus using
dataset version `1.5`. You can inspect the evidence behind the recorded results
and compare individual cases with your own evaluation runs.

## What's changed

The [evaluation snapshot directory](https://github.com/kemiblueoyes/python-rag-service/tree/main/evaluation/reports/doc-landscape-v1.5-2026-10-05)
now includes:

- **Retrieval reports** with returned evidence, relevance judgments, metrics, and
  case outcomes.
- **Answer reports** with generated answers, evidence-sufficiency results, and
  citation checks.
- **Human-review reports** with scores for support, completeness, unsupported
  details, and focus across 14 saved answers.
- **A matching dataset snapshot** with 22 queries, filters, source judgments, and
  answer expectations.

Each report is available as Markdown for reading and JSON for programmatic
comparison. The Recorded evaluation results page links to these files and
explains the findings and comparison limits.

## Known issues

The retrieval report records an October 3 run; the answer report and human review
record August 28 results. These are separate runs, even though they use the same
dataset version. The snapshots don't include the full historical index, an
implementation commit, or every retrieval setting, so they don't provide all the
inputs needed to reproduce those runs exactly.
