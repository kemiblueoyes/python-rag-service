title: Health

---

`GET /health` confirms that the service process has started and can respond.

It does not retrieve content, generate answers, inspect indexes, or check external dependencies. It is an operational liveness check, not a third RAG capability, and is not versioned under `/v1`.

No request body or API key is required.

## Successful response

Status: `200 OK`

```json
{
  "status": "ok"
}
```

See the [API Reference](/reference/health) for the generated endpoint documentation.
