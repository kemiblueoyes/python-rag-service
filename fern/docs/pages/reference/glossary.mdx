The glossary defines terms used throughout the Python RAG Service and its documentation.

## H

### Hybrid search

A retrieval approach that combines semantic and lexical search to find relevant content.

#### Example

The Python RAG Service retrieves candidates using vector search and BM25, then combines the ranked results before reranking.

**Also known as:** Hybrid retrieval

**Related terms:** [Lexical search](#lexical-search), [Semantic search](#semantic-search)

## L

### Lexical search

A retrieval approach that finds content by matching words and other textual features.

**Related terms:** [Semantic search](#semantic-search)

## S

### Semantic search

A retrieval approach that finds content based on meaning rather than relying only on exact keyword matches.
