The Python RAG Service turns documentation into retrievable chunks
for search and grounded answer generation.

The first implementation uses WordPress as its content source and
reference client, while the core indexing, retrieval,
answer-generation, API, and evaluation layers remain independent of
WordPress. This makes it possible to add other content sources and
clients without rebuilding the core retrieval system.

## Common use cases

Use the service when you want to:

- add documentation search to an application or website
- generate answers grounded in an indexed documentation corpus
- experiment with and evaluate retrieval strategies such as hybrid retrieval and reranking
- understand how indexing, retrieval, grounded generation, and evaluation fit together in a RAG system
- extend the service with additional content sources or client applications
