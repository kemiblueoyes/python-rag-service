---
title: Configure the RAG service
description: Install dependencies, configure environment variables, and run the Python RAG Service locally.
---

## Requirements

- Python 3.12
- [uv](https://docs.astral.sh/uv/)

## Install and configure

Clone the repository and install dependencies:

```bash
git clone https://github.com/kemiblueoyes/python-rag-service.git
cd python-rag-service
uv sync --dev
```

Create a local environment file:

```bash
cp .env.example .env
```

Add environment-specific URLs and credentials to `.env`. Never commit this file or place real API keys in `.env.example`.

Set `RAG_API_KEY` to a long random value. `POST /v1/search` and `POST /v1/answer` require that value in the `X-API-Key` header. `/health` remains unauthenticated.

## Run the service

```bash
uv run uvicorn rag_service.api.app:app --reload
```

Confirm the process is running:

```text
http://127.0.0.1:8000/health
```

Expected response:

```json
{
  "status": "ok"
}
```

FastAPI also serves interactive API documentation and the generated OpenAPI document:

```text
http://127.0.0.1:8000/docs
http://127.0.0.1:8000/openapi.json
```
