Install the Python RAG service on your computer and create a local environment file. This page stops once `.env` exists. Provider, content-source, and retrieval settings belong on the next page.

## Prerequisites

- Python 3.12
- [uv](https://docs.astral.sh/uv/)

<Steps toc={true}>
    ## Clone the repository

    Clone the Python RAG Service repository and open the project directory:

    ```bash
    git clone https://github.com/kemiblueoyes/python-rag-service.git
    cd python-rag-service
    ```

    Run the rest of these commands from that directory.

    ## Install dependencies

    Install the project dependencies, including the development tools:

    ```bash
    uv sync --dev
    ```

    `uv` creates the local Python environment and installs the packages the service needs.

    ## Create the environment file

    Copy the example environment file:

    ```bash
    cp .env.example .env
    ```

    `.env` is the local configuration file. Don't commit it, and don't put real API keys in `.env.example`.

    The Python RAG service is installed when this copy finishes. The example file already
    sets the embedding model, `QDRANT_URL`, `QDRANT_COLLECTION`, the retrieval settings,
    and WordPress collections to `posts` and `pages`. `RAG_API_KEY`, `VOYAGE_API_KEY`,
    and `WORDPRESS_BASE_URL` are still empty.
</Steps>
