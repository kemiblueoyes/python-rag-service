Search now retrieves candidates using both vector similarity and BM25 lexical
matching before combining and reranking the results. This gives the retrieval
pipeline access to both semantic similarity and exact-term matching.

## What's changed

The retrieval pipeline now:

- retrieves candidates from vector search and BM25 search
- combines the two ranked result sets using reciprocal rank fusion
- reranks the combined candidates before returning results
- applies support detection after retrieval to avoid returning results for
  queries the indexed documentation does not support
