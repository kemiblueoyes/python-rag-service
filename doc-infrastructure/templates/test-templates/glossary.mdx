The glossary defines terms used throughout the Python RAG Service and its documentation.

## H

### Hybrid search

A retrieval approach that combines semantic and lexical search to find relevant content.

#### Example

A query can be run against both a vector index and a BM25 index, then the two result sets can be combined before reranking.

**Also known as:** Hybrid retrieval

**Related terms:** [Lexical search](#lexical-search), [Semantic search](#semantic-search)

## L

### Lexical search

A retrieval approach that matches queries and documents based on words and other textual features.

**Related terms:** [Hybrid search](#hybrid-search), [Semantic search](#semantic-search)

## R

### Reciprocal rank fusion

A ranking method that combines results from multiple retrieval methods by using the position of each result in those ranked lists.

**Also known as:** RRF

**Related terms:** [Hybrid search](#hybrid-search)

## S

### Semantic search

A retrieval approach that uses vector representations to find content with similar meaning to a query.

**Related terms:** [Hybrid search](#hybrid-search), [Lexical search](#lexical-search)
