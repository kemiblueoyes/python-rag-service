Use the full indexing workflow to create the initial documentation index from a
configured WordPress source. The indexing process creates canonical documents,
chunks, embeddings, and vector records that make the source content available
for retrieval.

## Prerequisites

**[Configure the service](/#)**: Configure the required providers and content source.

## Run the full indexing command

Run the project's full indexing command against the configured WordPress source.

Allow the indexing process to complete before verifying the generated artifacts.

</Steps>

The initial WordPress documentation index is now created and ready to verify.

## Verification

Confirm that the indexing run produced the expected artifacts:

- **Canonical documents** — WordPress source content was converted into the canonical document model.
- **Chunks** — the canonical documents were divided into retrieval-ready chunks.
- **Embeddings** — embeddings were generated for the indexed chunks.
- **Vector records** — the resulting records were stored for retrieval.
