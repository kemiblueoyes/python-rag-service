### Retrieval-augmented generation

A technique in which a system retrieves relevant source content before generating a response, so the response can be grounded in information 
from those sources.

**Also known as:** RAG

**Example:** The Python RAG Service retrieves relevant documentation for a user’s question and passes that evidence to the language model 
when generating an answer.
