Use `POST /v1/search` to retrieve documentation relevant to a query. You can narrow the search with optional filters and 
control the maximum number of results returned.

## Prerequisites

Before searching documentation:

- Create an initial documentation index.
- Configure API-key authentication for the RAG API.

<Steps toc={true}>

## Send a search request

Send a query to `POST /v1/search` with your API key.

Use tabs to provide equivalent cURL and Python request examples.

## Refine the search

Add supported filters when you want to narrow the content considered for retrieval.

Set `limit` when you want to control the maximum number of results returned.

See the Search API reference for the supported request fields and filters.

## Handle the response

A successful search returns documentation relevant to the query.

Use the returned result information, such as the title, section, excerpt, and source URL, to present the retrieved 
documentation to the user.

## Handle an empty result

A search can return no results when the service does not find documentation that sufficiently supports the query.

Handle an empty result explicitly in the client rather than treating it as an API failure.

</Steps>
